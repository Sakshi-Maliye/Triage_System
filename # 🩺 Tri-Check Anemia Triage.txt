# 🩺 Tri-Check Anemia Triage

A non-invasive anemia screening system that analyses **three physiological points**
— Eyes (Conjunctiva), Tongue, and Nails — using MediaPipe landmark tracking,
CLAHE colour normalisation, and a Deep Neural Network.

---

```

├── app.py                    ← Flask web server
```

## ⚙️ VS Code Setup (Step-by-Step)

### 1. Open the project folder
```
File → Open Folder → select TriCheck_Anemia/
```

### 2. Create & activate a virtual environment
Open the integrated terminal (`Ctrl+`` ` or Terminal → New Terminal):

**Windows**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```
> TensorFlow can be large (~600 MB). Allow a few minutes.

## 🗂️ Organise Your Data

### India_Eyes  (`data/India_Eyes/`)
- Place raw eye images inside numbered subfolders (`1/`, `2/`, …) **or** directly in the folder.
- Add a `metadata.csv` with columns: `filename`, `Hb`, `Anaemic` (Yes/No).
- If no CSV exists, place images in subfolders named `anemic/` and `healthy/`.

### India_Tongue  (`data/India_Tongue/`)
- Place tongue images directly in this folder.
- Binary mask PNGs go in `data/India_Tongue/groundtruth/mask/`
  (same stem name as the source image, e.g. `img001.png` → `img001.png`).

### India_Nails  (`data/India_Nails/`)
Four subfolders (create if missing):
```
data/India_Nails/
    healthy_nail/      ← label 0
    blue_finger/       ← label 1
    clubbing/          ← label 1
    pitting/           ← label 1
```

## 🚀 Order of Operations

### Step 1 — Extract features
```bash
python src/data_engine.py
```
Generates `tri_check_master.csv` in the project root.

### Step 2 — Train the model
```bash
python src/train_model.py
```
Trains for **up to 100 epochs** (early stopping kicks in when validation AUC
stops improving). Saves:
- `models/deep_anemia_model.h5`
- `models/scaler.pkl`
- `models/training_history.png`

### Step 3 — Launch the web app
```bash
python app.py
```
Open your browser at **http://127.0.0.1:5000**

Upload one photo each of the lower eyelid, tongue, and index fingernail.
The system returns a Triage Assessment: **Healthy / Moderate Risk / Severe Risk**.

## 🧠 How It Works

| Stage | Detail |
|-------|--------|
| **Landmarking** | MediaPipe FaceMesh locates lower eyelid (LM 145/159) and tongue center (LM 13); Hands locates index fingertip (LM 8) |
| **Preprocessing** | CLAHE equalisation on the LAB L-channel corrects uneven illumination |
| **Features** | R/G ratio + LAB a* channel (redness axis) + mean RGB per ROI |
| **Model** | 3-block Dense DNN with BatchNorm + LeakyReLU + Dropout, trained with Binary Crossentropy |
| **Triage** | Average of three channel probabilities → Healthy (<40%) / Moderate (40–65%) / Severe (>65%) |

## 🔧 Troubleshooting

| Problem | Fix |
|---------|-----|
| `Model not found` | Run `python src/train_model.py` first |
| `No records extracted` | Check that images exist in the correct `data/` subfolders |
| MediaPipe import error | Upgrade: `pip install --upgrade mediapipe` |
| TensorFlow GPU warning | Safe to ignore on CPU-only machines |
| Port 5000 in use | Change to `app.run(port=5001)` in `app.py` |
